Connect this device

Anyone with the link can look at this shelf. To change it from this device, paste a GitHub access token that can only edit this one repo. You make the token once, then paste it on each device you use.

  1. Open GitHub’s new token page (signed in as you).
  2. Name it Goosebumps Tracker and pick an expiration. A year is fine.
  3. Under Repository access, choose Only select repositories, then pick goosebumps-tracker from the Select repositories menu that appears.
  4. Under Permissions, a Repositories section now shows next to Account. Click Add permissions there, choose Contents, and change Read-only to Read and write. Leave Account empty.
  5. Click Generate token, copy the token (it starts with github_pat_), and paste it below.

The token is saved in this browser only and is sent to nowhere but GitHub. On iPhone, a home-screen icon keeps its own storage, so connect once inside it too.

This device can change your shelf. Each tap saves to GitHub about a second later, and your other devices pick it up within 30 seconds or as soon as you switch back to them.
